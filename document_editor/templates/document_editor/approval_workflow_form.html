About Approval Workflows

An approval workflow allows you to route your document through a series of approvers before it's finalized.

Approval Process
  1. Create the workflow
  2. Add approval steps in the desired order
  3. Start the workflow to notify the first approver
  4. Each approver reviews and approves or rejects the document
  5. When all approvers have approved, the document is marked as approved
Document Status
  • Draft - Initial workflow setup
  • Pending Approval - Workflow started, awaiting approvals
  • Approved - All approvers have approved
  • Rejected - An approver has rejected the document
  • Canceled - Workflow canceled by creator
