About Approval Workflows

Starting the approval workflow initiates the formal review process for your document.

Workflow Process
  1. The document status changes to "Under Review"
  2. The first approver is notified to review the document
  3. Each approver reviews and either approves or rejects
  4. If rejected, the workflow stops and you must revise the document
  5. If all approvers approve, the document is marked as "Approved"
Document Status
  • Draft - Initial workflow setup
  • Under Review - Workflow started, awaiting approvals
  • Approved - All approvers have approved
  • Rejected - An approver has rejected the document
  • Canceled - Workflow canceled by creator
